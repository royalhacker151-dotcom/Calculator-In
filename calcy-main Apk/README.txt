Calculator - Android project
Package name: com.jahangeer.calculator

OPTION 1 - Android Studio
  1. Open this folder in Android Studio (File > Open).
  2. Build > Build APK(s). APK: app/build/outputs/apk/debug/Calculator-debug.apk

OPTION 2 - GitHub (no installation needed)
  1. Create a new GitHub repository and upload everything in this folder
     (keep the .github folder).
  2. Open the Actions tab > "Build APK" > Run workflow (it also runs on every push).
  3. When finished, download "Calculator-APK" from the run's Artifacts.

The calculator page is app/src/main/assets/index.html.
Download saves into Downloads/Calculator (Files app). Share opens the share sheet.
Needs Android 10 or newer.
